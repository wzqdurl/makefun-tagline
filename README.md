## How it runs

`main.py` is Python 3.13, standard library only, no network, no clock, no
randomness. It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt`) and exits 0. Two runs write byte-identical files.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
